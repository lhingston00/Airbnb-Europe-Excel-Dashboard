## 📊 Project Overview
This project is an interactive Excel dashboard designed to analyse Airbnb listings across major European cities. By looking at a dataset of over 41,000 listings, the goal of this analysis is to uncover key market trends, pricing strategies, and accommodation availability to provide valuable insights for both potential hosts and travellers.

The dashboard visualises critical Key Performance Indicators (KPIs) such as average pricing, room type distribution, and guest satisfaction across cities like Amsterdam, Paris, Lisbon, Rome, and Athens.

## 🛠️ Tools Used
* **Microsoft Excel**: Data cleaning, Pivot Tables, Pivot Charts, and interactive Dashboard creation.
* **Data Visualisation**: Customised bar charts, doughnut charts, and conditional formatting to make complex data easily digestible.

## 💡 Key Insights
* **Pricing Trends by City:** Amsterdam emerges as the premium market (averaging ~€573/night), followed closely by Paris (~€393/night). Conversely, cities like Athens offer much more budget-friendly options (~€152/night).
* **Market Mix (Room Types):** The European market is heavily dominated by 'Entire home/apt' listings (approx. 67.8%), followed by 'Private rooms' (31.5%), with 'Shared rooms' making up less than 1% of the inventory.
* **Guest Preferences:** Highlights how variables like cleanliness ratings, host status (Superhost), and distance to the city centre impact overall guest satisfaction and listing prices.

## 📁 How to View and Interact with This Dashboard
Because GitHub does not support viewing interactive Excel dashboards directly in the browser, you will need to download the file to see it in action:

3. Open the file in Microsoft Excel to interact with the slicers, pivot tables, and charts!
